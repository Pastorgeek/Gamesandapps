Sound timing game

Clap Clock Challenge

Choose 1–4 players. Each player gets three rounds. Press Go to reveal a random target from 3–10 seconds, then clap once to start the hidden timer and clap again to stop it. Lowest total miss wins.

Game setup

Microphone access is needed so the browser can detect clap spikes. Audio is processed locally in this page.
